# Phase 2 Glossary

Simple meanings for the words used in Phase 2. Each one links to the note that explains it.

## A to C

- **ACID:** the four guarantees of a database transaction. [[29 Relational Databases#Transactions|More]]
- **Adjacency list:** storing a graph as each node's list of neighbours. [[21 Graphs#Adjacency List|More]]
- **Aggregate function:** turns many rows into one value, such as SUM. [[30 SQL#Summarizing with GROUP BY|More]]
- **Amortized cost:** the average cost per action over many actions. [[16 Complexity Analysis#Amortized Cost|More]]
- **API:** a way for programs to talk to each other. [[32 HTTP and HTTPS#JSON APIs and REST|More]]
- **Backtracking:** choose, explore, then undo the choice. [[23 Algorithm Patterns#Recursion and Backtracking|More]]
- **Bandwidth:** how much data can move per second. [[31 Networking Fundamentals#Two Words People Confuse|More]]
- **BFS:** visiting a graph in rings, using a queue. [[25 Graph Algorithms#Breadth-First Search|More]]
- **Big-O:** a description of how work grows with input size. [[16 Complexity Analysis#The One Picture to Remember|More]]
- **Binary search:** finding an item by halving a sorted list. [[22 Searching and Sorting#Binary Search|More]]
- **BST:** a tree where left is smaller and right is bigger. [[20 Trees and Heaps#Binary Search Trees|More]]
- **Cache:** a nearby copy that saves repeated work. [[19 Hash Tables#Build an LRU Cache|More]]
- **Call stack:** the stack that tracks running functions. [[18 Stacks, Queues and Deques#The Call Stack|More]]
- **Class:** a blueprint for making objects. [[26 Object-Oriented Programming#Classes and Objects|More]]
- **Closure:** a function that remembers where it was made. [[27 Programming Paradigms#Closures|More]]
- **Cohesion:** how well a class's parts belong together. [[26 Object-Oriented Programming#Coupling and Cohesion|More]]
- **Collision:** two keys landing in the same box. [[19 Hash Tables#3. Handle Collisions|More]]
- **Combination:** a choice of items where order doesn't matter. [[15 Discrete Mathematics#Combinations - Order Doesn't Matter|More]]
- **Composition:** building an object from other objects. [[26 Object-Oriented Programming#Composition over Inheritance|More]]
- **Constraint:** a rule that the database enforces. [[29 Relational Databases#Constraints - Rules the Database Enforces|More]]
- **Cookie:** small data your browser saves and sends back. [[32 HTTP and HTTPS#Stateless and Cookies|More]]
- **CORS:** how a server permits pages from other sites to read its responses. [[32 HTTP and HTTPS#CORS|More]]
- **Coupling:** how much classes depend on each other. [[26 Object-Oriented Programming#Coupling and Cohesion|More]]
- **CTE:** a named step inside a SQL query. [[30 SQL#CTEs - Giving a Query a Name|More]]

- **DAG:** a directed graph with no cycles. [[21 Graphs#More Words You Need|More]]
- **Data structure:** a way of organizing data. [[17 Arrays and Linked Lists#The Big Idea|More]]
- **Declarative:** saying what you want, not how to do it. [[27 Programming Paradigms#Declarative|More]]
- **Deque:** a queue open at both ends. [[18 Stacks, Queues and Deques#Deques|More]]
- **DFS:** going as deep as possible, using a stack or recursion. [[25 Graph Algorithms#Depth-First Search|More]]
- **Dijkstra:** an algorithm for finding the cheapest route. [[25 Graph Algorithms#Shortest Paths with Dijkstra|More]]
- **DNS:** turns names into IP addresses. [[31 Networking Fundamentals#DNS - The Internet's Phone Book|More]]
- **DRY:** Don't Repeat Yourself. [[28 Clean Code#Rule 4 - Avoid Duplication, But Not Too Early|More]]
- **Dynamic array:** an array that grows automatically. [[17 Arrays and Linked Lists#Dynamic Arrays|More]]
- **Dynamic programming:** remembering answers to avoid repeat work. [[24 Dynamic Programming#The Big Idea|More]]
- **Encapsulation:** protecting data behind methods, or wrapping network data in headers. [[26 Object-Oriented Programming#Encapsulation|OOP]] · [[31 Networking Fundamentals#Encapsulation - Parcels Inside Parcels|Networking]]
- **Foreign key:** a column that points to a row in another table. [[29 Relational Databases#Foreign Keys and One-to-Many|More]]
- **Function (math):** each input has exactly one output. [[15 Discrete Mathematics#Relations and Functions|More]]
- **Graph:** things plus connections. [[21 Graphs#The Big Idea|More]]
- **Greedy:** taking the best choice at each step. [[23 Algorithm Patterns#Greedy Algorithms|More]]
- **GROUP BY:** makes piles of rows to summarize. [[30 SQL#Summarizing with GROUP BY|More]]
- **Guard clause:** an early return that handles a problem first. [[28 Clean Code#Rule 3 - Use Guard Clauses|More]]
- **Handshake:** the first messages that set up a connection. [[31 Networking Fundamentals#The TCP Handshake|More]]
- **Hash function:** turns a key into a number. [[19 Hash Tables#1. The Hash Function|More]]
- **Hash table:** finds values by key, almost instantly. [[19 Hash Tables#The Big Idea|More]]
- **Heap:** a tree with the smallest item on top. [[20 Trees and Heaps#Heaps|More]]
- **HTTP:** the request and response language of the web. [[32 HTTP and HTTPS#Requests and Responses|More]]
- **HTTPS:** HTTP inside an encrypted connection. [[32 HTTP and HTTPS#HTTPS - The Secure Version|More]]

## I to O

- **Idempotent:** doing it twice has the same effect as once. [[32 HTTP and HTTPS#Methods - What Do You Want to Do?|More]]
- **Index (database):** a structure that finds rows quickly. [[29 Relational Databases#Indexes in One Picture|More]]
- **Inheritance:** a class reusing a parent class. [[26 Object-Oriented Programming#Inheritance|More]]
- **Interface:** a contract saying what methods exist. [[26 Object-Oriented Programming#Abstraction|More]]
- **IP address:** identifies a computer on a network. [[31 Networking Fundamentals#Finding a Computer - IP Addresses and Ports|More]]
- **Join:** matching rows from two tables. [[30 SQL#Joins in One Picture|More]]
- **KISS:** Keep It Simple. [[28 Clean Code#Rule 7 - Keep It Simple|More]]
- **Latency:** how long one piece of data takes to arrive. [[31 Networking Fundamentals#Two Words People Confuse|More]]
- **Layers:** dividing networking into separate jobs. [[31 Networking Fundamentals#Layers - The Key Idea|More]]
- **Linked list:** a chain of nodes joined by pointers. [[17 Arrays and Linked Lists#Linked Lists|More]]
- **Load factor:** how full a hash table is. [[19 Hash Tables#The Load Factor|More]]
- **LRU cache:** a cache that discards the least recently used item. [[19 Hash Tables#Build an LRU Cache|More]]
- **Memoization:** saving answers from recursive calls. [[24 Dynamic Programming#Fix 1 - Memoization (Top-Down)|More]]
- **Method:** a function that belongs to an object. [[26 Object-Oriented Programming#Understanding Each Part|More]]
- **Minimum spanning tree:** the cheapest way to connect all nodes. [[25 Graph Algorithms#Minimum Spanning Trees|More]]
- **Modular arithmetic:** math that wraps around, like a clock. [[15 Discrete Mathematics#Clock Math - Modular Arithmetic|More]]
- **Node:** one item in a linked list, tree or graph. [[17 Arrays and Linked Lists#Linked Lists|More]]
- **Normalization:** storing each fact in only one place. [[29 Relational Databases#Normalization - Store Each Fact Once|More]]
- **NULL:** a missing or unknown value. [[29 Relational Databases#What Is NULL?|More]]
- **Object:** one real thing built from a class. [[26 Object-Oriented Programming#Classes and Objects|More]]
- **OSI model:** a seven-layer vocabulary for networks. [[31 Networking Fundamentals#OSI and TCP-IP|More]]
